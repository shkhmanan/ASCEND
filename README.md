# ASCEND — Training RPG

ASCEND is a local-first workout tracking Progressive Web App.

This repository is the application source. `index.html`, `sw.js`, `manifest.json`, and the icon assets are required to host it as a PWA.

## Privacy
Your workout data is saved locally in your browser, not committed to this repository. Do not upload personal JSON backups here.

## Deployment
Enable GitHub Pages for the `main` branch, root folder, using GitHub repository Settings → Pages. A Pages address is active only after GitHub reports the deployment as successful.

## Data backups
Export your training data under ASCEND → Settings before switching browsers, URLs, or devices, then import at the new address.
